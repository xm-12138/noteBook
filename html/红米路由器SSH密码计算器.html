使用说明

  • 开启 SSH 后用 用户名 root 登录，密码即本页按 SN 算出的 默认密码（小写字母 + 数字，共 8 位）。
  • SN 中区分大小写，请完整、准确地输入，例如 57941/F4U711396。
  • 登录后建议立刻执行 passwd 修改成你自己的强密码。
  • 连接时若提示 no matching host key type found / Their offer: ssh-rsa，在 SSH 命令中加参数：
    ssh -oHostKeyAlgorithms=+ssh-rsa root@192.168.31.1

适用范围

  • 新一代机型（SN 含 “/”）：BE3600 / BE6500 / AX3000 / AX3600 / AX6 / AX6000 / AX9000 / AC2100 / AC2350 / AX1800 / AX5400 等。
  • 旧款机型（SN 无 “/”）：R1D / R1CM / R3 / R2D / R1CL 等，使用另一套盐值。

算法说明

  • 密码 = MD5( SN + 盐值 ) 的前 8 位十六进制。
  • SN 含 “/” 时盐值：6d2df50a-250f-4a30-a5e6-d44fb0960aa0
  • SN 不含 “/” 时盐值：A2E371B0-B34B-48A5-8C40-A7133F3B5D88
  • 该算法与知名在线算号器 miwifi.dev/ssh 完全一致，本页在浏览器本地计算，不上传任何数据。
